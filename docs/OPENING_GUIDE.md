# Opening Guide

Open `powerbi/Project4_Final_Dashboard.pbip` in Power BI Desktop.

If Power BI asks to apply project changes, choose **Apply**. If a data warning appears after opening, use **Home > Refresh**.

The report contains two pages:

- **Registry Operations**
- **Data Quality & Review Queue**

All records in this project are simulated test records. No real patient data, MIMIC-IV data, or restricted clinical source data is included.
